# Welcome to the Museum

Not every project needs to be maintained forever to deserve a place on display.

Some are finished. Some are still evolving. Others simply represent an interesting experiment, a useful idea, or a small piece of development history.

Here, repositories are exhibits rather than products.

## Visiting the collection

Feel free to explore, learn from, reuse, or draw inspiration from the projects on display.

Just keep in mind that not every exhibit is actively maintained. Some are preserved exactly as they were, quirks included.

If something still works, that's a bonus. If it doesn't, consider it part of the historical experience.
